# A 股可读版改造设计

**日期：** 2026-07-24  
**项目：** OrgLab Sentinel（orglab-sentinel-prototype）  
**状态：** 已通过对话确认，待实现计划  

## 目标

在保持现有多 Agent 演示原型结构的前提下，完成三件事：

1. **美股语境全面改为 A 股语境**（持仓、情景、公告来源、货币）
2. **轻度简化用户可见术语**（文案中文化 + 抽屉少露技术细节）
3. **引入四类轻量图表**，提升可读性

不做：真实行情接入、品牌改名、删除「组织实验」页、重型图表库、路由/状态管理重构。

## 已确认决策

| 项 | 选择 |
|----|------|
| 改造深度 | 本地化 + 轻度简化（非大幅重做体验） |
| 演示持仓 | 宁德时代 `300750.SZ` 38%、比亚迪 `002594.SZ` 34%、中芯国际 `688981.SH` 28% |
| 图表 | 全选：仓位环形图、风险半圆仪表、组织实验对比柱图、分析流程时间线 |
| 术语简化 | 界面文案 + 用户可见技术细节一并白话化 |
| 实现路径 | **A 股可读版**：保留三页导航与 Agent 流程，嵌入图表并去黑话 |

## 数据与 A 股本地化

### 持仓

- 货币：`$` → `¥`（模拟资产金额保持演示量级，如 ¥286,420）
- 市场标签：`NASDAQ` → `深交所` / `上交所·科创板`
- 股票：`NVDA`/`AAPL`/`TSLA` → 上述三只 A 股；仓位比例可沿用现演示比例

### 情景映射

| 情景 id | 短名 | 标的 | 说明 |
|---------|------|------|------|
| `earnings` | 财报指标承压 | 宁德时代 | 毛利率低于情景阈值；新闻 + 公告一致 |
| `supply` | 供应链中断 | 比亚迪 | 供应商停产弱信号；公告未确认 |
| `rumor` | 未证实传闻 | 中芯国际 | 社交传闻隔离，不计入组合风险 |

### 来源替换（仍为 MOCK）

| 原美股语境 | A 股语境 |
|------------|----------|
| SEC / 10-K / 8-K | 巨潮资讯 / 交易所公告 / 定期报告 |
| XBRL facts | 财报附注 / 结构化财务字段（演示样本） |
| Finnhub / 券商 | 文案改为「未连接行情或券商」 |

`dataMode: MOCK`、人工门禁、不自动交易等治理约束保持不变。

## 界面与术语

### 保留

- 三页：监控台、Agent 团队、组织实验
- 相位动画、故障注入、用户「已阅读 ≠ 交易」门禁
- OrgLab Sentinel 品牌名

### 用户可见术语替换（示例）

| 原表述 | 新表述 |
|--------|--------|
| EvidenceBrief | 证据简报 |
| Patch / namespace 路径 | 变更记录（抽屉少露路径字符串） |
| SEC / XBRL / fixture://… | 交易所公告 / 财报数据 / 演示样本 |
| 英文 eyebrow（如 SOURCE-SPECIALIST…） | 中文短标签（如「A 股组合风险助手」） |
| schema / data_mode / provider 元数据行 | 「来源类型、更新时间、可信度」等白话字段 |

内部 JS 字段名（如 `evidenceBriefs`、`schemaVersion`）可保留，避免无谓破坏测试契约；**用户界面字符串**必须白话化。

## 图表

全部使用轻量 React + SVG/CSS 组件，**不新增** recharts / echarts / chart.js 等重型依赖。

| 图表 | 位置 | 行为 |
|------|------|------|
| 仓位环形图 | 监控台持仓区 | 按 `holdings` 占比着色；可保留列表 |
| 风险半圆仪表 | 监控台指标区 | 显示 `riskScore`；未就绪/隔离时显示占位文案 |
| 分析流程时间线 | 监控台流程区 | 随 `phase` 高亮；替代或增强现有 pipeline 节点 |
| 组织实验对比柱图 | 组织实验页 | 对比三种协作结构的演示综合分 |

建议目录：`src/components/charts/`（如 `AllocationDonut.jsx`、`RiskGauge.jsx`、`OrgScoreBars.jsx`、`PipelineTimeline.jsx`）。

## 架构与改动边界

```
demoData.js     → A 股持仓、情景文案、公告来源文案
simulation.js   → 流程逻辑基本不动；故障/账本文案白话化
App.jsx         → 嵌入图表；抽屉与标签去黑话
styles.css      → 图表与时间线样式
test/           → 更新 ticker / 文案相关断言
```

### 数据流（不变）

选情景 → 相位动画 → 新闻/公告简报并行 → 主管汇总 → 风险报告 → 用户确认（不交易）

### 错误与降级（沿用现有）

- 新闻超时、证据冲突故障注入逻辑保留
- 图表在 `phase` 未完成或 `riskScore === null` 时显示「计算中 / 暂缓评分」等占位，不伪造分数

## 验收标准

1. 用户可见层无美股代码、SEC、美元符号（演示文案）
2. 四类图表可见，并随情景 / 相位 / 实验结果更新
3. 抽屉与主要标签无 schema、namespace、fixture 路径等黑话
4. `npm test` 与 `npm run build` 通过
5. 仍明确标注：模拟数据 · 不自动交易

## 明确不做

- 不接真实行情或券商 API
- 不改品牌名 OrgLab Sentinel
- 不重构路由或全局状态方案
- 不删除「组织实验」页
- 不引入重型图表库
