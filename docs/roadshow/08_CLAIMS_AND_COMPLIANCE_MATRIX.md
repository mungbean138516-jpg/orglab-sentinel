## 数字使用规则

每个数字必须属于以下一类：

1. **可溯源事实**：附来源、日期和口径；
2. **演示值**：页面写 `MOCK / DEMO`；
3. **目标假设**：显式写“目标假设”，不能写成已经达到。

优先删除以下无解释数字：

- `68/100` 风险分
- `29%–32%` 建议仓位
- `−6% 至 −9%` 压力影响
- 没有真实运行依据的秒级响应

如确需保留，必须同时展示输入、公式、规则版本和非投资建议说明。


行业情况只能用文字概括并添加脚注。不要复制大段报告或使用无出处截图。

## 阿里生态口径

正确方式是说明“为什么需要”：

- 千问解决推理；
- 百炼解决编排和追踪；
- 魔搭解决评测；
- 钉钉解决人工复核；
- 通义／夸克解决未来用户触达。

禁止将第三方 MCP 服务表述为阿里自有数据，也不要将“出现在魔搭市场”表述为“已经集成”。

## 金融场景红线

- 不荐股；
- 不承诺收益；
- 不输出确定涨跌；
- 不连接券商；
- 不自动下单；
- 不代替持牌机构；
- 不用“风险低”暗示“可以买”；
- 热搜和社交信息只能作为待核验触发。

建议把“建议仓位”统一改成：

- 虚拟暴露概览
- 需要关注
- 等待核验
- 证据不足
- 验证报告

## 路演禁用词

除非有可核验证据，否则禁止：

- 全球首创
- 万亿参数
- 秒级全市场
- 100% 准确
- 显著提高收益
- 完全消除风险
- 已经打通阿里全生态
- 实时监控所有 A 股

推荐替换：

- “概念级目标方案”
- “理论可行”
- “当前 MOCK 已验证流程”
- “下一阶段可接入”
- “目标假设”
