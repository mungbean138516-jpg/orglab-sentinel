> 状态：`ACTIVE DECISION LOG`  
> 原则：意见可以匿名，但产品取舍必须有理由和验收标准。

## 已确认方向

> 以中国普通投资者的信息核验和风险理解为首个场景；不以盈利或荐股为目标。路演重点展示多 Agent 的来源分工、交叉验证、证据可追溯和安全降级，并将其表达为可复用的可信证据引擎。

## UI 颜色规则

| 颜色 | 唯一主要语义 | 示例 |
| --- | --- | --- |
| 青色 | 品牌、主要交互 | 查看完整报告、当前导航 |
| 绿色 | 已验证、完成 | 一级来源已验证 |
| 黄色／橙色 | 待关注、待核验 | 数据过期、来源覆盖不足 |
| 红色 | 高风险、冲突、异常 | 证据冲突、工具失败 |
| 蓝色 | 来源、中性数据 | 公告、数据字段、连接信息 |
| 紫色 | 主管与组织层 | 综合、实验模式 |

颜色不能是唯一信息载体；标签必须同时写文字状态。

## 页面信息层级

### 第一层：5 秒能读懂

- 当前事件
- 风险／证据状态
- MOCK
- 是否需要核验

### 第二层：30 秒能理解

- 虚拟暴露图
- 两个专项 Agent 状态
- 一致点、冲突、未知项

### 第三层：需要时展开

- 完整 EvidenceBrief
- 证据 locator
- Patch 账本
- 方法和规则版本

## 推迟项

- 真实交易所与新闻 API
